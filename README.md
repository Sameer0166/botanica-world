## 📖 Overview

**Botanica World** helps students, home cooks, and nature enthusiasts recognize **220 edible plant species** from around the globe—connecting each plant's botanical origin, regional names, and visual appearance with its everyday culinary uses and nutritional benefits.

---

## 🌿 What's Included (220 Specimens)

- **Comprehensive Plant Taxonomy:** Covers tropical & temperate fruits, leafy greens, root & stem vegetables, whole grains, legumes/pulses, tree nuts, seeds, culinary herbs, and aromatic spices.
- **Multilingual & Scientific Context:** Every specimen includes common English names, regional names, scientific binomial nomenclature, native geographic origins, and major cultivating regions.

---

## ✨ Core Features

### 🖼️ Dual Visual Modes
- **Photo & Vector Toggle:** Switch seamlessly between real-world botanical photography and clean vector botanical illustrations.

### 🎧 Interactive Study & Memory Aids
- **Slow & Fast Audio Pronunciation:** Built-in Web Speech synthesis (`🐢 Slow` / `⚡ Fast`) on every card and detail cue card.
- **Student Mode:** Adapts botanical descriptions into clear, accessible explanations for younger learners.
- **Memory Hide:** Blurs plant titles across the grid for active-recall self-testing.
- **Letter-by-Letter Spelling Cue Cards:** Click any card to view spelling tiles, native origins, culinary applications, and nutrition superpowers.
- **Revision List & Mastery Tracking:** Save difficult specimens for review and track mastered cards locally with `localStorage`.

### 🎯 Interactive Quiz Arena & Certificate Export
- **Multi-Mode 10-Question Quizzes:** Test visual plant identification, audio spelling, nutrition knowledge, culinary uses, and botanical geography.
- **Downloadable Certificates:** Scoring **70% or higher** unlocks a personalized certificate with **instant PNG download** and **landscape PDF/print export**.

### 🖨️ Offline Printable Study Sheets
- Built-in `@media print` styling renders clean **2-column printable study sheets** with page-break protection so students can save offline PDF revision guides effortlessly.

---

## 🛠️ Tech Stack

- **Core:** Semantic HTML5, Modern CSS3 (CSS Grid, Flexbox, `@media print`), Vanilla ES6+ JavaScript
- **Browser & Data APIs:** Wikipedia REST API, Wikimedia Commons API, Web Speech Synthesis API, HTML5 Canvas API, and `localStorage`
- **Deployment:** Zero-dependency single-page app hosted on GitHub Pages
